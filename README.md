# Ch Financeiro

Chat de finanças pessoais com relatórios e categorias. Para publicar, abra **Settings → Pages**, selecione **Deploy from a branch** → **main** → **/(root)** → **Save**.

**Privacidade:** o repositório contém apenas código. Os lançamentos são salvos no navegador local e não sincronizam entre aparelhos. Faça backup JSON antes de trocar de dispositivo. Um serviço de autenticação e banco de dados com políticas de acesso será necessário para sincronização segura. Nunca adicione senhas ou dados financeiros ao repositório público.
